RULES:
- value_chain_layers: 3-5 layers that reflect THIS market's real structure (not always the same layers).
- segments: 2-4 per layer with real sub_segments (imported/onshore, OEM/CDMO/CRO, etc. when applicable).
- discovery_prompts: 12-18 prompts — at least one per major segment, covering the full chain.
- seed_companies: 18-30 REAL, established companies that are genuine MAJOR PLAYERS / market
  leaders in THIS market and geography — the recognised companies a market-research report would
  profile as "Key Players". Span EVERY value-chain segment/section. Only real companies you are
  confident exist, each with its real official domain (bare hostname). Favour recognised leaders
  and breadth; never pad with made-up or uncertain names. If the query names specific company
  types/functions/sections, you MUST name several real companies for EACH one (e.g. if "Contract
  Manufacturer / CDMO" is requested, list multiple real contract manufacturers/CDMOs), and add a
  discovery_prompt targeting each requested type. Do not leave a requested type with no companies.
- NEVER use listicle wording: top, best, list, ranking, largest, leading 50.
- Prefer: official site, headquarters, manufacturing plant, corporate profile, GMP certified, authorized distributor.
- Domains: bare hostnames only (example.com).
- LANGUAGE — PRODUCE BOTH ENGLISH AND LOCAL (do not pick only one):
  * ALWAYS keep a strong set of English discovery_prompts — these find global/international
    suppliers active in the country and English-language pages.
  * DETECT the geography's main business language; if it is NOT English (Brazil -> Portuguese;
    Spain & Latin America -> Spanish; Germany/Austria -> German; France -> French; Italy ->
    Italian; Japan -> Japanese; China -> Chinese; Korea -> Korean; etc.), ALSO write 5-8
    discovery_prompts IN THAT LANGUAGE using the LOCAL term for the product (e.g. "disco de
    ruptura fabricante Brasil"). Local players' sites are in the local language and are missed by
    English-only queries.
  * Aim for a roughly EVEN split between English and local-language prompts — NEVER output prompts
    in only one language. Add the local product term(s) to industry_terms and relevance_keywords.
- Adapt layers to the query industry. Examples:
